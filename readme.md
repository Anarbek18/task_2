## Задание 2: API

### Автотесты для API Stellar Burgers

Тестируются эндпоинты: создание пользователя, логин, изменение данных пользователя, создание заказа, получение заказов пользователя. Для каждого эндпоинта — отдельный класс в отдельном файле.

### Структура проекта

- `tests` - тесты, разделённые по эндпоинтам (`test_create_user.py`, `test_login_user.py` и т.д.)
- `helpers.py` - методы для запросов к API и генерации данных
- `data.py` - URL и тексты ошибок
- `conftest.py` - фикстуры: данные пользователя создаются перед тестом и удаляются после него
- `allure_report` - Allure-отчёт

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов**

> `$ pytest`

**Формирование Allure-отчёта**

> `$ allure generate allure_results -o allure_report --clean`
